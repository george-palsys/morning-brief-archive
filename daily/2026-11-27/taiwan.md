### PayNow 電子發票系統的對外 API 兩度遭異常存取，多家商家的消費者資料外洩

- 發生什麼事：金流業者 PayNow 的官方公告寫，11/11 發票系統的對外 API 出現大量異常存取，11/13 通報國稅局；11/20 加值中心的對外 API 再次遭異常存取，已經封鎖並改成 IP 白名單，也更新了通報。公告列的外洩欄位是訂單編號、載具資訊、買家姓名、電子郵件、聯絡電話、購買商品及交易金額，不含信用卡卡號與銀行帳戶。iThome 在 2026-11-26 報導：受影響的約 500 家商家、約 281 萬張不重複的電子發票，已經出現冒用資料的詐騙訊息；這兩個數字與詐騙訊息只在 iThome 看到，官方公告沒有寫。
- 影響：這是「API 金鑰外流後被大量代理 IP 批次讀取」的型態（攻擊手法的說法出自 iThome）。對金融與電商客戶，重點是對外 API 有沒有來源限制、有沒有異常流量的偵測，以及委外平台出事時自己要不要通報。用到這個發票平台的商家要通知消費者提防詐騙。
- 來源：https://gateway.paynow.com.tw/news/164 ；https://www.ithome.com.tw/news/180833

### 瓦城代子公司泰味國際發布資安重訊：委外的雲端發票平台遭異常存取，影響 290 人

- 發生什麼事：上市公司瓦城（2729）在公開資訊觀測站代子公司泰味國際發布重大訊息（發言日期 115/11/25，時間 20:19:31）：委外的購物網站服務廠商所委外的雲端發票平台，發生異常資料存取，影響人數 290 人；公司評估對營運沒有重大影響，如果有求償會向委外廠商求償。這個雲端發票平台和上一則的 PayNow 是不是同一個，重訊沒有寫，無法確認。
- 影響：出事的是「委外廠商再委外」的平台，發重訊的是最上游的上市公司。客戶在盤點供應鏈時，第二層以下的委外廠商（發票、簡訊、物流這類加值服務）手上有哪些個資，通常不在合約的資安條款裡。
- 來源：https://mopsov.twse.com.tw/mops/web/ajax_t05sr01_1?firstin=true&stp=1&step=1&SEQ_NO=8&SPOKE_TIME=201931&SPOKE_DATE=20261125&COMPANY_ID=2729 ；https://www.ithome.com.tw/news/180806

### 【後續】刑事局示警：假冒短劇 App 的手機木馬盜轉網路銀行存款

- 發生什麼事：內政部在 115-11-26 的新聞稿說明這一波手法：假冒短劇 App 的 APK 安裝後，顯示假的 Google Play 更新畫面，要求建立 VPN 連線來擋掉手機內建的安全檢查，再安裝沒有圖示的木馬，誘使使用者開啟無障礙權限，之後在數十秒內自行取得簡訊、檔案、相機、麥克風、裝置管理員等 12 類授權。這是 TWCERT/CC 在 2026-11-24 發出警訊的後續。iThome 在 2026-11-26 報導：9 月到 11/21 超過 100 起、財損超過 1,742 萬元，涉及 22 家金融機構；這些數字只在 iThome 看到。
- 影響：木馬拿到無障礙權限與簡訊之後，可以代替使用者操作行動銀行並讀取簡訊驗證碼，銀行端的簡訊 OTP 擋不住。iThome 報導金管會表示銀行公會將研議強化措施。對金融業客戶，行動銀行 App 偵測無障礙服務與側載 App 的能力會被主管機關關注。
- 來源：https://www.moi.gov.tw/News_Content.aspx?n=4&s=343530 ；https://www.ithome.com.tw/news/180826
